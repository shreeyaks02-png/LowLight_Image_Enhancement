Ablation Study

1. Objective

To understand how much the different components (Classical Computer Vision and Deep Learning) contribute to enhancing the low-light images.

2. Experiments

Experiment Name | Configuration | Purpose

Experiment 1 | Classical CV Only | Classic image enhancement

Experiment 2 | Pretrained Zero DCE Only | Deep Learning based enhancement

Experiment 3 | Hybrid (85% Classical CV, 15% Zero DCE) | Combination of enhancement methods

3. Observations

Classical CV: Increased brightness and clarity in images using classic image processing techniques.

Zero DCE: Used Deep Learning based low-light enhancement.

Hybrid Fusion: Combined the two methods to create a balanced enhanced image.

4. Conclusion

This method uses a combination of classic image processing and pre-trained Deep Learning. From the results we can see what can be expected from each of these methods. More testing will need to be done on a variety of low-light images to determine the effectiveness of each component. This is a qualitative comparison of the different components. An Ablation Study with controlled and repeatable measures will be needed to get a quantitative conclusion.
